## 四、有没有免费的？—— 结论先行

> ⚠️ **千问没有任何永久免费的 API 模型。** 所有模型通过 API 调用都需要付费，官网定价页面对每个模型都列出了明确的价格。所谓的"免费额度"是新用户试用福利（90 天有效，到期即收费）。

免费使用千问模型，实际上只有以下途径：

### 1️⃣ Qwen Studio — 免费聊天，但这不是 API

- 网址：**https://chat.qwen.ai**
- Web / iOS / Android / 桌面客户端
- 完全免费，无配额，可以用旗舰模型
- 支持对话、生图、视频、文档分析、联网搜索
- ⚠️ 这是聊天 App，**不能作为 API 集成到自己的应用里**

### 2️⃣ 开源模型自己部署 — 模型免费，但需要硬件

所有标 ✅ Apache 2.0 的模型均可**免费下载、商用、修改**。模型权重不花钱，但得自己买/租 GPU 跑。

| 场景 | 推荐模型 | 显存需求 |
|------|----------|----------|
| 最强开源 | Qwen3.5-397B-A17B | 多卡 |
| Agent 编程 | Qwen3.6-27B | ~20GB |
| 轻量编程 | Qwen3.6-35B-A3B | ~8GB |
| 中等任务 | Qwen3.5-27B / Qwen3-32B | ~20GB |
| 日常使用 | Qwen3.5-9B / Qwen3-14B | ~10GB |
| 代码辅助 | Qwen3-Coder-Next | ~8GB |
| 边缘设备 | Qwen3.5-4B / Qwen3-4B | ~4GB |

### 3️⃣ 新人试用额度 — 临时免费，90 天

**千问AI平台**（platform.qianwenai.com）：每模型 100 万 Token，90 天有效。
**阿里云百炼**（aliyun.com/product/bailian）：覆盖 70+ 模型，也 90 天有效。

过期后自动转为按量付费。

### 4️⃣ 第三方平台临时免费

- OpenRouter 上 `qwen/qwen3.6-plus-preview:free`，预览期间免费，但数据会被收集

## 七、业务场景选型：Jira 工单审查

> 场景来源：`.agents/skills/jira-ticket-review/SKILL.md`
> 场景描述：对 Jira HIM Bug 工单进行信息充分性审查 —— 模板剥离 → 分类校验 → 场景匹配 → 规则判定 → 结构化 JSON 输出

### 7.1 场景特征

| 维度 | 评估 |
|------|------|
| 任务类型 | 规则化的文本理解 + 分类 + 判定 |
| 推理深度 | 低（规则匹配，非数学/逻辑推理） |
| 上下文需求 | 低（单工单几千 token） |
| 输出格式 | 结构化 JSON（6 字段，严格格式） |
| 语言 | 中文 |
| 精度要求 | 高（漏查 = 废单，误判 = 返工） |
| 关键能力 | 指令遵循、场景归类准确性、结构化输出 |
| 不需要的能力 | 推理链、代码生成、多模态 |

### 7.4 选型理由

**千问首选 Qwen3.7-Plus，DeepSeek 首选 deepseek-v3.2，两者同档位：**

| 对比维度 | Qwen3.7-Plus | deepseek-v3.2 |
|----------|-------------|---------------|
| 档次 | 通用 Plus 均衡型 | 通用均衡型 |
| 单次成本 | ¥0.0064 | ¥0.0055 |
| 中文能力 | 原生中文，一流 | 中文强 |
| 结构化输出 | 原生支持 | 支持 |
| 当前促销 | 8 折 | 无 |

**排除项：**

- **推理模型（deepseek-r1、蒸馏系列）**：工单审查是规则匹配不是逻辑推理，推理链对任务无帮助，白白多花钱
- **轻量模型（deepseek-v4-flash）**：15 种场景归类 + 模板剥离需要一定理解力，Flash 级模型有误判风险。返工成本远大于省下的 ¥0.003/次
- **旗舰模型（deepseek-v4-pro、Qwen3.7-Max）**：规则判定型任务不需要旗舰级能力

### 7.5 落地建议

1. 用百炼新人免费额度（千问+DeepSeek 各有 100 万 Token），各跑 100 张真实工单做 A/B 对比
2. 关注两个风险点：模板剥离对模板变体的鲁棒性、边界工单的场景归类准确率
3. 成本差距可忽略（¥0.0055 vs ¥0.0064），**以准确率定胜负**
4. 建议开启 structured output 避免 JSON 格式错误
