# T7 env 包 spec

> 实现任务规格。**本文自包含，是执行者的唯一必读依据**；背景出处（非必读）：`docs/designs/2026-09-14-skill-platform-spec-v3/design/dependency-rules.md` 第 1 类。

## 1. 目标

产出 `@easemob/agent-env` 包：**进程环境变量的唯一读取口**。任何模块需要进程级部署配置（端口、目录、日志级别、超时默认值等），只能从本包读，禁止散点 `process.env`。

## 2. 背景知识（执行所需的最小上下文）

- 依赖管理四类归宿：环境变量 = 第 1 类——进程级、部署期确定、初始化后不可变。本包是该类的唯一落地口。
- 本包是**纯函数集合**（无状态、无初始化、无缓存）——每次调用即读 `process.env` 并解析。启动时统一解析+校验是**调用方**（server 装配根）的纪律：它在启动时把所有需要的变量一口气读完，缺必需项即 fail-fast。
- 注意区分：业务的密钥/环境配置（控制台管理、按业务隔离、运行期变化）不归本包，那归 EnvProvider（后续任务）。
- 运行时零依赖（连 workspace 包都不依赖）。

## 3. 范围与不做清单

**本任务做**：`getString` / `getNumber` / `getBoolean` 三个纯函数 + `EnvError`。

**本任务不做**：

- `.env` 文件加载（部署环境由 systemd/docker 注入；本地开发需要时后续再议）；
- 缓存、watch、热更新（初始化后不可变，无需）；
- schema 声明式校验框架（三个函数够用，不建抽象）。

## 5. 详细规格

```ts
/** 环境变量读取错误：变量名 + 原因都在 message 里（fail-fast 时可直接进日志） */
export class EnvError extends Error {}

export interface StringOptions {
  default?: string;   // 未设置时返回它；与 required 同时给时 default 优先
  required?: boolean; // true 且未设置 → 抛 EnvError
}
export interface NumberOptions {
  default?: number;   // 同 StringOptions.default
  required?: boolean; // 同 StringOptions.required
  min?: number;       // 下界（含）；越界 → EnvError
  max?: number;       // 上界（含）；越界 → EnvError
}
export interface BooleanOptions {
  default?: boolean;   // 同 StringOptions.default
  required?: boolean;  // 同 StringOptions.required
}

/** 读取字符串。空串视为未设置；required 而未设置 → EnvError */
export function getString(name: string, options?: StringOptions): string;

/** 读取数字。非法数字（NaN）/ 越界 → EnvError；其余同 getString */
export function getNumber(name: string, options?: NumberOptions): number;

/** 读取布尔：'true'/'1' → true，'false'/'0' → false（大小写不敏感）；其他值 → EnvError */
export function getBoolean(name: string, options?: BooleanOptions): boolean;
```

实现要点：

1. 统一判定：`undefined` 或 `''`（trim 后）= 未设置 → 有 default 返回 default，required 抛 EnvError，否则返回 undefined 对应的兜底（见下）；
2. 既未设置又非 required 且无 default：返回类型怎么给？——**签名上 options 带 default 或 required 时返回对应类型；都不给时返回 `undefined`**。实现上用函数重载表达（`required: true` 或有 default → 必然有值；否则 `| undefined`），调用方编译期就能区分；
3. `getNumber`：`Number(raw)` 解析（不接受 `'12abc'`——`Number` 对此返回 NaN，正好抛错）；`min`/`max` 越界抛错；
4. 错误信息统一格式：`环境变量 <NAME> <原因>`（原因：未设置/非法数字/越界/非法布尔）。

## 6. 测试清单

（测试中用 `process.env.X = ...` / `delete process.env.X` 直接操纵，每个用例自清理）

- getString：正常读取；未设置 + default → default；未设置 + required → EnvError（含变量名）；未设置无 default 无 required → undefined；空串 = 未设置；
- getNumber：正常解析；`'12abc'` → EnvError；min/max 越界 → EnvError；default/required/未设置三分支；
- getBoolean：`'true'/'1'/'TRUE'` → true；`'false'/'0'` → false；`'yes'` 等 → EnvError；
- 类型收窄：重载签名在 typecheck 层面可区分（用 `satisfies` 或赋值断言验证 required 调用返回非 undefined）。

## 7. 验收标准

1. 包级与根级六项检查全绿；
2. 运行时零依赖（不 import 任何 workspace 包，只读 `process.env`）；
3. 导出签名与本文 §5 一致。
