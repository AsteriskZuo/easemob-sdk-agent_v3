# your-skill（示例）

这是模板自带的示例 skill，演示最小形状：一个含 `SKILL.md` 的目录就是一个 skill。

被 `sdk.agent({ skills: ["your-skill"] })` 引用时，本文件全文会被平台内联进系统提示词。
真正的 skill 在这里写：角色设定、工作流程、输出格式要求、禁区清单——全部是给大模型看的指令。

参考写法：

## 角色

（一句话说明这个 skill 让模型扮演什么角色）

## 工作流程

1. （第一步做什么）
2. （第二步做什么）

## 输出要求

- （产出的格式/结构约束）

## 禁区

- （不允许做什么）
